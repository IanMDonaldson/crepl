# CREPL
Just a REPL for C that's inspired by Common Lisp SBCL's REPL. Mostly the only thing it does over LLVM's C REPL is add error recovery :)

# Install
```make && make install```
installs to your $HOME/.local/bin, so make sure it exists and is on your $PATH

# Usage
use :help to get a list of commands you can use
